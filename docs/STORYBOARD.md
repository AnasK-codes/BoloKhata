# 60-second demo storyboard

Film **on a real phone, screen recorded with the phone's own audio**, portrait, quiet room, synthetic data only (the seed catalog and customers are fictional). Do one dry run first, then film the whole thing in one take if you can. Open **Settings, Latency HUD** on beforehand so the HUD appears under the bill.

**Rules**
- Every number shown or said must come from the running app. Do not edit timings. If a latency figure goes in a caption, read it off the HUD of that very take and state the conditions in the post (phone model, network, where the gateway runs).
- Speak naturally. The lines below are what to say; small wording changes are fine, the app is meant to cope with that.
- Seed state before filming: use **Settings, Demo data reset**, then the opening balances are Sharma ji ₹120 and Verma ji ₹300.
